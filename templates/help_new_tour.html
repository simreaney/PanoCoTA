Build Your First Tour

Follow these steps in order from top to bottom inside the editor UI.

Step 1: Upload a 360 panorama image

  • Open Add Scene and upload your panorama image file.
  • After upload, choose that file in the 360 Panorama Image dropdown.

Step 2: Create your first scene

  • Enter a scene title in Add Scene.
  • Click Add Scene.
  • The title is also used as the scene ID.

Step 3: Add hotspots

  1. Open Add Hotspot.
  2. Choose Source Scene.
  3. Set Pitch and Yaw or click Use Current View.
  4. Enter hotspot title text.

Hotspot type setup:

  • Scene Navigation: choose Target Scene.
  • Graphed Data: upload or select CSV, then pick x/y columns and subplot options.
  • Image: upload or select a 2D image and optional caption.
  • Free Text: enter Free Text Content to show on hover.

Step 4: Save your tour

  • Open Save Tour.
  • Select an existing name or choose create new and enter one.
  • Click Save Tour To Disk.

Step 5: Load and continue editing later

  • Open Load Tour.
  • Select a saved tour and click Load Tour From Disk.

Step 6: Publish to GitHub Pages (optional)

  • Scroll to Publish To GitHub at the bottom of the sidebar.
  • Set owner, scope, branch, and token, then click Export and Publish.
Tip: Save your tour first before publishing to avoid missing-tour errors.
