PanoCoTA

Panoramic Content and Tours for Academia

Conceptualised and vibe-coded by A J Neill (JLU Giessen)

PanoCoTA is a free, open-source web app for building interactive 360° tours that embed graphed data, 2D images and text directly into panoramic scenes — turning field deployments, monitoring sites and research infrastructure into explorable, shareable stories for scientific communication.

What it does

  • Build 360° tours from your own panorama photos (full-sphere or partial coverage).
  • Pin hotspots anywhere in a scene: scene links, animated graphs, images, free text, always-visible text panels, and web links.
  • Plot CSV data as up to 8 stacked subplots (line, scatter, bar) — with per-subplot X columns and shared Y-axes for direct comparison.
  • Save, load, and edit tours in the browser — no installation needed.
  • One-click publish: export a static, hostable tour package to GitHub Pages and share a link.

Hotspot types

Scene link — jump between panoramas
Graph — (animated) CSV data plots
Image — 2D photos with captions
Free text — hover cards
Text panel — always visible
Web link — external resources

How to use it

  1. Upload a 360° panorama and create a scene.
  2. Add hotspots and click once in the panorama to place them.
  3. Save your tour — it can be reloaded and edited any time.
  4. Publish to GitHub Pages and share the link with anyone.

Perfect for

  • Field campaign and monitoring-site documentation
  • Thesis and project reporting with embedded data
  • Workshops, open days, and public engagement
  • Teaching: students explore real datasets in context
